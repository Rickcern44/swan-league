# Feature records

These folders are implementation history: what each `SWAN-n` piece of work set out to do, its tasks, and what was delivered. They are not the source of truth for scope or phasing.

- The PRD (`docs/reference/Swan League App — Product Requirements.md`) is canonical for requirements and phases (§11).
- [docs/project.md](../project.md) is the delivery index: current phase, evidence level, and what comes next.
- A feature's `status: done` means its implementation tasks are finished. It does not mean its end-to-end exit criteria were demonstrated; each record says which evidence exists.
